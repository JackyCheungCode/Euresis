Integration Client

工作流模块可以通过 integrationClient.call('serper', payload) 调用已启用服务。具体请求格式由服务适配器处理；当前工作流中的示例数据不会因为填写 API Key 而自动替换为真实数据。

import { integrationClient } from './services/integrations.js';
const result = await integrationClient.call('tavily', { query: 'solar distributors Germany' });
